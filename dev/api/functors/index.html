JuliaTopology.Comma — Type
Comma(F, G)
F ↓ G

The comma category (F ↓ G) of functors F: A → C and G: B → C, i.e. objects of Hom(Cat[A], Cat[C]) and Hom(Cat[B], Cat[C]).

Its objects are GenericCommas (a, b, h), with a an object of A, b one of B, and h: F(a) → G(b) a morphism of C. Its morphisms (a, b, h) → (a′, b′, h′) are GenericMorphCommas (α, β), with α: a → a′ in A and β: b → b′ in B such that G(β) ∘ h == h′ ∘ F(α).

Standardized Interface

  • source(o), target(o), arrow(o) — the a, b and h of an object o
  • compose(n, m), id(o) — componentwise

Interface Specification Assumptions

  • F, G are functors with the same codomain C
  • o is an object of Comma(F, G); m, n are morphisms between them

JuliaTopology.FreeCat — Type
FreeCat(vertices, arrows)

The free category on a finite graph, used as the shape of a diagram. Its objects are the vertices, a collection of Symbols, written J[:X]. Its morphisms are the paths along its arrows, given as label => (source => target) pairs, e.g.

J = FreeCat((:X, :Y), (f = :X => :Y, g = :X => :Y))

Standardized Interface

  • generator(J, :f) — the arrow f as a morphism
  • compose(q, p), id(J[:X]) — joining paths, and the empty path
  • discreteShape, emptyShape, parallelPairShape, cospanShape, spanShape — common shapes

Interface Specification Assumptions

  • J :: FreeCat; p, q are its morphisms

JuliaTopology.Op — Type
Op(C)

The opposite category Cᵒᵖ of a category C: the same objects, with every morphism reversed. An object X of C is the object op(X) of Op(C), and a morphism f: X → Y of C is the morphism op(f): op(Y) → op(X) of Op(C); op undoes itself, and op(Op(C)) == C.

Everything about Op(C) follows from C by duality: compose(g, f) is op(compose(op(f), op(g))), epimorphisms and monomorphisms trade places, an initial object of Op(C) is a terminal object of C, and so on. A cocone is a cone in an opposite category: Cocone(D) == Op(Cone(op(D))).

Standardized Interface

  • op(C), op(X), op(f) — the opposite of a category, object or morphism
  • compose, id, firstDifference, isEpi, isMono, isIso, inv, canonicalHom, terminal, initial — by duality from C
  • vertices, generators — for a shape C, those of C with every generator reversed

JuliaTopology.FunctorCat — Type
FunctorCat(J, C)

The functor category [J, C] for a shape J (a category defining vertices and generators, e.g. a FreeCat) and a category C. Its objects are the diagrams of shape J in C, i.e. objects of Hom(Cat[J], Cat[C]) (see diagram), written FunctorCat(J, C)[D]. Its morphisms are natural transformations, GenericMorphFunctorCats.

Standardized Interface

  • compose(θ, η), id(D), firstDifference(η, θ) — componentwise

Interface Specification Assumptions

  • D is an object of FunctorCat(J, C); η, θ are its morphisms
source
JuliaTopology.GenericMorphFunctorCat — Type
GenericMorphFunctorCat(diagram)

A natural transformation η: D₁ → D₂ between diagrams of shape J in C, a morphism of FunctorCat(J, C): a diagram of shape J in the arrow category arrowCategory(C), whose object at each vertex j is the component η_j: D₁(j) → D₂(j) and whose morphism at each arrow a is the square (D₁(a), D₂(a)). That this square commutes is exactly naturality. Build one with Hom(D₁, D₂)[(j = η_j, …)]; components reads the components back.

JuliaTopology.FuncDiagram — Type
FuncDiagram(objects, arrows)

A diagram of shape J in a category C, i.e. a functor from J to C, an object of Hom(Cat[J], Cat[C]): NamedTuples assigning an object of C to each vertex and a morphism of C to each arrow of J. Build one with diagram, or parallelPair, cospan, span or discrete. The shape J may be any category defining vertices and generators, such as a FreeCat. Applied to a vertex J[:X] it gives the object at X, and applied to a path, the composite of the arrows along it.

JuliaTopology.Cocone — Method
Cocone(D)

The category of cocones under a diagram D of shape J in C: the opposite of the category of cones over op(D), i.e. Op(Cone(op(D))), since a cocone is exactly a cone in the opposite category. Everything about cocones follows by duality; they are built and read with the morphisms of C themselves, which are converted with op as needed. A cocone is an apex X with a leg D(j) → X for each vertex j, commuting with the arrows of D, written Cocone(D)[(A = legA, B = legB, …)], or Cocone(D)[X, legs] for an empty diagram. A morphism of cocones is a morphism u between their apexes commuting with the legs, written Hom(c₁, c₂)[u]. A colimit of D is an initial object of Cocone(D), see colimit. Cocone is also the type of every cocone category, for dispatch.

Standardized Interface

  • apex(c), legs(c), leg(c, :A) — the apex and legs of a cocone c
source
JuliaTopology.Cone — Method
Cone(D)

The category of cones over a diagram D of shape J in C, i.e. the comma category Δ ↓ D of the diagonal functor Δ: C → [J, C] and D, regarded as a functor from Point by constant. A cone is an apex X with a leg X → D(j) for each vertex j, commuting with the arrows of D, written Cone(D)[(A = legA, B = legB, …)], or Cone(D)[X, legs] for an empty diagram. A morphism of cones is a morphism u between their apexes commuting with the legs, written Hom(c₁, c₂)[u]. A limit of D is a terminal object of Cone(D), see limit. Cone is also the type of every cone category, for dispatch.

Standardized Interface

  • apex(c), legs(c), leg(c, :A) — the apex and legs of a cone c
source
JuliaTopology.Coslice — Method
Coslice(X)

The coslice category X/C under an object X of C: the cocones under the one-object diagram constant(X). Its objects are the morphisms f: X → A, written Coslice(X)[f], and its morphisms from f: X → A to g: X → B are the morphisms h: A → B with h ∘ f == g, written Hom(Coslice(X)[f], Coslice(X)[g])[h]. Its initial object is id(X), up to isomorphism: initial(Coslice(X)).

source
JuliaTopology.Slice — Method
Slice(X)

The slice category C/X over an object X of C: the cones over the one-object diagram constant(X). Its objects are the morphisms f: A → X, written Slice(X)[f], and its morphisms from f: A → X to g: B → X are the morphisms h: A → B with g ∘ h == f, written Hom(Slice(X)[f], Slice(X)[g])[h]. Its terminal object is id(X), up to isomorphism: terminal(Slice(X)).
