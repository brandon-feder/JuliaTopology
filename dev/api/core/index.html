JuliaTopology.checkInCategory — Method
checkInCategory(obj, Cat::Category)

Check whether an object belongs in a particular category, returning true if it does, and throwing a NotInCategory explaining why otherwise. This is the sole membership check a category needs to overload. This generic fallback always throws a NotInCategory error.

source
JuliaTopology.checkInterface — Method
checkInterface(object, category::Category)

Checks whether object satisfies the interface required by category. This generic fallback matches any category that hasn't defined its own, more specific method, but it warns that no such check exists, then returns true rather than erroring. Define checkInterface(obj::SomeType, cat::SomeCategory) = ... to actually enforce an interface for a given category. Such methods should return true or throw an InterfaceViolation explaining what is wrong.

JuliaTopology.@checkCallable — Macro
@checkCallable object category argtypes

Throw an InterfaceViolation unless object, once wrapped as an ObjectInCategory{typeof(object), typeof(category)}, is callable with arguments of types argtypes, other than by a generic fallback which only throws. The check is on types since the wrapper does not exist yet when checkInterface runs. Meant for use inside checkInterface overloads.

source
JuliaTopology.@checkMethod — Macro
@checkMethod object category f argtypes

Throw an InterfaceViolation unless the function f is defined and has a method for argtypes. Here f must be a name such as cardinality or Base.getindex. Meant for use inside checkInterface overloads.

Base.inv — Method
inv(f::OIC{<:Any, <:HomLike})

The inverse of a morphism f in Iso(X, Y), a morphism in Iso(Y, X).

This generic fallback always throws: an ArgumentError when f is not in an Iso, since only isomorphisms have inverses, and otherwise an InterfaceViolation; implementations of morphisms overload it for their own types.

JuliaTopology.canonicalHom — Method
canonicalHom(A, B)

The canonical morphism from A to B: for objects of one category, an object of Hom(A, B) (or a more specific Epi, Mono, Iso); for two categories, a functor between them. Throws a NoCanonicalHomError when none is defined; categories overload this for their own objects.

JuliaTopology.firstDifference — Function

Compare morphisms f and g with the same domain and codomain: nothing when they agree, and otherwise the first place they differ, as (at, left, right), where f gives left and g gives right at at. Each implementation of morphisms overloads it for its own.
