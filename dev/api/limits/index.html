Limits and colimits

Limits and colimits of finite sets.

JuliaTopology.CategoryOfElements — Type
CategoryOfElements(D)
∫(D)

The category of elements ∫D of a diagram D of finite sets: its objects are the pairs (vertex = j, element = x) with x an element of D(j), and it is generated by an arrow (j, x) → (k, D(f)(x)) for each arrow f: j → k of the shape and element x. For a single set X, it is the discrete category ascat(X). Its objects form a set, objectSet, and its connected components are the colimit of D, see componentMap and π₀.

JuliaTopology.FuncHomFrom — Type
FuncHomFrom(X)

The covariant hom-functor Hom(X, -): FinSet → FinSet, sending a set Y to homSet(X, Y) and a map g: Y → Z to f ↦ g ∘ f. Build it with homFrom.

source
JuliaTopology.FuncHomTo — Type
FuncHomTo(X)

The contravariant hom-functor Hom(-, X): FinSetᵒᵖ → FinSet, sending op(Y) to homSet(Y, X) and op(g), for g: Y → Z, to f ↦ f ∘ g. Build it with homTo.

JuliaTopology.HomSet — Type
HomSet(A, B)

The set of all maps from the finite set A to B, as a lazy finite set: there are |B|^|A| of them, each made only when iterated. Build it as a FinSet object with homSet.

JuliaTopology.:⊔ — Method
A ⊔ B

The disjoint union of finite sets A and B as a set, the apex of coproduct(A, B).

source
JuliaTopology.canonicalHom — Method
canonicalHom(X, Y)

For finite sets X and Y, the unique map from X to Y, which exists when Y has one element (e.g. terminal(FinSet)) or X has none (e.g. initial(FinSet)). Throws a NoCanonicalHomError otherwise.

source
JuliaTopology.canonicalHom — Method
canonicalHom(c, L)

For cones c and L over the same diagram of finite sets, the unique morphism of cones from c to L: the map sending each x in the apex of c to the one p in the apex of L with leg(L, j)(p) == leg(c, j)(x) for every vertex j. Throws a NoCanonicalHomError unless there is exactly one such p for each x, as there is when L is a limit, e.g. built by limit.

source
JuliaTopology.coequalizer — Method
coequalizer(f, g)

The coequalizer of maps f, g: X → Y of finite sets, the colimit of parallelPair(f, g): a cocone whose apex is Y divided by the smallest equivalence relating f(x) and g(x) for each x.

source
JuliaTopology.colimit — Method
colimit(D)

The colimit of a diagram D, an initial object of Cocone(D), i.e. initial(Cocone(D)): the universal cocone under D, through which every other cocone factors uniquely, by canonicalHom(colimit(D), c). Since a cocone is a cone in the opposite category, this is op of the terminal cone over op(D).

For finite sets, the apex is the set of connected components of the category of elements ∫(D), each shown by a representative (vertex = j, element = x), and the leg at j is the inclusion of D(j) into the disjoint union of the sets followed by componentMap(∫D), which sends (j, x) to its component. It is computed once, from the sets as they are when it is built.

source
JuliaTopology.componentMap — Method
componentMap(E::CategoryOfElements)

The quotient map of the category of elements E = ∫D onto its connected components, a surjection from objectSet(E) to π₀(E): it sends each object (j, x) to its component, shown by the first member of the component. Two objects are connected exactly when they have the same image, and the members of a component are its fiber. The components are computed once, from the sets as they are when it is called.

JuliaTopology.coproduct — Method
coproduct(X₁, X₂, …)
coproduct(; A = X₁, B = X₂, …)

The coproduct of finite sets, the colimit of discrete(…): a cocone whose apex is their disjoint union and whose legs are the inclusions.

JuliaTopology.curry — Method
curry(f, C, A)

For a map f: C × A → B, the map C → homSet(A, B) sending c to a ↦ f(c, a). uncurry undoes it.

JuliaTopology.element — Method
element(p)

The element picked out by a morphism p: T → X of finite sets from a one-element set T, such as a globalElement.

source
JuliaTopology.equalizer — Method
equalizer(f, g)

The equalizer of maps f, g: X → Y of finite sets, the limit of parallelPair(f, g): a cone whose apex has an element (X = x, Y = f(x)) for each x with f(x) == g(x).

source
JuliaTopology.evaluation — Method
evaluation(A, B)

The evaluation map homSet(A, B) × A → B, sending (f, a) to f(a).

source
JuliaTopology.fiber — Method
fiber(f, y)

The fiber of a map f: A → B of finite sets over an element y of B: the pullback of f along the map 1 → B picking out y, i.e. pullback(f, globalElement(y)). Its apex has an element (A = x, …) for each x that f sends to y, and its leg at :A is the inclusion of the fiber into A. For example, the fibers of componentMap are the components.

source
JuliaTopology.globalElement — Method
globalElement(x)

The element x of a finite set X as a morphism 1 → X from the terminal set terminal(FinSet), picking out x. The elements of X and the maps 1 → X correspond exactly; element goes back, and a map f: X → Y applied to a global element composes with it, agreeing with globalElement(f(x)) (see firstDifference).

source
JuliaTopology.homFrom — Method
homFrom(X)

The representable functor Hom(X, -), see FuncHomFrom.

source
JuliaTopology.homSet — Method
homSet(A, B)

The finite set of all maps from A to B, whose elements are the morphisms of Hom(A, B), so that f in homSet(A, B) for any of them. Its elements are made only when iterated. With it, FinSet is cartesian closed: see evaluation, curry and uncurry. The maps from the one-point set are the elements of B, see globalElement, and the unique map of canonicalHom is the only element of a hom-set with one.

source
JuliaTopology.homTo — Method
homTo(X)

The representable functor Hom(-, X) from the opposite of FinSet, see FuncHomTo.

source
JuliaTopology.image — Method
image(f)

The image of a map f: A → B of finite sets, the set of values of f: the object through which imageFactorization factors f.

source
JuliaTopology.imageFactorization — Method
imageFactorization(f)

The factorization of a map f: A → B of finite sets through its image I, as (epi = e, mono = m): the surjection e: A → I sending a to f(a), and the inclusion m: I → B, with m ∘ e == f.

source
JuliaTopology.initial — Method
initial(C::Category)

An initial object of C, the apex of the colimit of the empty diagram in C, e.g. the empty set for C = FinSet. canonicalHom(I, X) is the unique morphism out of it.

source
JuliaTopology.limit — Method
limit(D)

The limit of a diagram D, a terminal object of Cone(D), i.e. terminal(Cone(D)): the universal cone over D, through which every other cone factors uniquely, by canonicalHom(c, limit(D)).

source
JuliaTopology.objectSet — Method
objectSet(E::CategoryOfElements)

The objects of the category of elements E = ∫D, as a finite set: the disjoint union of the sets of D, whose elements are the pairs (vertex = j, element = x).

source
JuliaTopology.pointCones — Method
pointCones(D)

The cones over a diagram D of finite sets from the one-point set, each given by where its legs send the point: the NamedTuples with an element of D(j) for each vertex j such that D(f)(x_j) == x_k for each arrow f: j → k. These are the elements of the limit of D, since lim D ≅ Hom(1, lim D) is the set of cones from 1. They are found by choosing an element for each vertex in turn: a vertex reached by an arrow from a chosen vertex is determined by it, and any other ranges over its set.

source
JuliaTopology.product — Method
product(X₁, X₂, …)
product(; A = X₁, B = X₂, …)

The product of finite sets, the limit of discrete(…): a cone whose apex has the elements (X1 = x₁, X2 = x₂, …), or (A = x₁, B = x₂, …), and whose legs are the projections.

source
JuliaTopology.pullback — Method
pullback(f, g)

The pullback of maps f: A → C and g: B → C of finite sets, the limit of cospan(f, g): a cone whose apex has an element (A = a, B = b, C = f(a)) for each a, b with f(a) == g(b).

source
JuliaTopology.pushout — Method
pushout(f, g)

The pushout of maps f: C → A and g: C → B of finite sets, the colimit of span(f, g): a cocone whose apex is the disjoint union of A and B, with f(c) and g(c) identified for each c.

source
JuliaTopology.terminal — Method
terminal(C::Category)

A terminal object of C, the apex of the limit of the empty diagram in C, e.g. the one-point set for C = FinSet. canonicalHom(X, T) is the unique morphism into it.

source
JuliaTopology.terminal — Method
terminal(K)

A terminal object of the category K: for a category of cones, a limit; for a category of cocones (the opposite of one of cones), a colimit; for a slice, the identity. Terminal objects of comma categories are universal arrows, so this is the one universal construction the others are built from.

For cones over a diagram D of finite sets, the apex of the terminal cone is the set of pointCones of D, i.e. of NamedTuples (A = a, B = b, …) respecting every arrow, and its legs are the projections p ↦ object(p)[j]. For a diagram without arrows, a product, the apex is Iterators.product of its sets, whose elements are only made when iterated; otherwise it is computed once, from the sets as they are when it is built.

source
JuliaTopology.uncurry — Method
uncurry(g, A)

For a map g: C → homSet(A, B), the map C × A → B sending (c, a) to g(c)(a); it undoes curry.

source
JuliaTopology.universalArrow — Method
universalArrow(K)

The universal arrow of a comma category K, i.e. its terminal object, see terminal.

JuliaTopology.π₀ — Method
π₀(E::CategoryOfElements)

The set of connected components of E, each shown by its first member: the codomain of componentMap(E). Each call computes it anew, so to use it with the map, take codomain(category(componentMap(E))).

∫(D)

The category of elements of a diagram D of finite sets, see CategoryOfElements.

A × B
