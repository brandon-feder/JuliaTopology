Printing and settings

How objects and messages are printed, and global settings.

JuliaTopology.codeclr — Method
codeclr(code::AbstractString)

code syntax highlighted as Julia code. Use it for code snippets in messages, e.g. a method to overload.

source
JuliaTopology.coloredPrint — Function
coloredPrint(x::Union{OIC, Category})::String

The compact, single line display of x: an object as name ∈ category, and a category by its name alone. Julia datatypes are omitted, any category nested inside another is shortened to the names of its objects, e.g. f ∈ Hom(X, Y), and each name is cut short after MAX_NAME_LENGTH characters.

source
JuliaTopology.coloredTree — Method
coloredTree(x::Union{OIC, Category})::String

The full, multi-line display of x: every object with its Julia datatype, and below it, the category it lives in, recursively. Each child is labeled by its relation to its parent (∈, of, domain, ...).

source
JuliaTopology.name — Method
name(cat::Category)::String

Returns a string which is what the category should be called. By default returns string(nameof(typeof(cat)))

source
JuliaTopology.name — Method
name(oic::OIC)::String

Returns a string which is what an instance of ObjectInCategory should be called. By default this is the compact repr of the underlying object. Overload it for objects whose repr is long or unclear; in the compact display it is cut short after MAX_NAME_LENGTH characters anyway.

source
JuliaTopology.overloadHint — Method
overloadHint(fname, args::NTuple{3, AbstractString}...)

The end of a message telling the user which method to overload. Each argument is (argname, description, type): description says in English which values the method applies to (e.g. "an element of Hom(X, Y)"), and type is its exact type in the method's signature. fname is the function's name, or nothing when the first argument is itself the thing being called.

source
JuliaTopology.typeString — Method
typeString(T)::String

string(T), writing ObjectInCategory by its alias OIC as messages do.

source
JuliaTopology.valclr — Method
valclr(x)

repr(x) colored as a plain Julia value, i.e. one not wrapped in any category. Use it when interpolating such values into messages.

source
JuliaTopology.COLORFUL — Constant
COLORFUL = true

Whether Base.show and Base.print output should be colorful.

source
JuliaTopology.MAX_NAME_LENGTH — Constant
MAX_NAME_LENGTH = 60

The most characters of a name shown in the compact display of an object; longer names are cut short with …. The tree display always shows the full name.

source
JuliaTopology.MAX_SET_MAP_PAIRS_SHOWN — Constant
MAX_SET_MAP_PAIRS_SHOWN = 3

The most pairs of a map of finite sets listed in its name, e.g. {1 ↦ :a, 2 ↦ :b, 3 ↦ :c, …}, and the most elements listed in its error messages.

source

JuliaTopology.InterfaceViolation — Type
struct InterfaceViolation <: Exception

Thrown by checkInterface when object does not satisfy the interface required by a category.

Members

  • object - The object being wrapped
  • category - The category which the object is in
  • reason::AbstractString - An explanation of the violation

JuliaTopology.@annotated — Macro
@annotated "...$x..."

An interpolated string which keeps the colors of what is interpolated into it, i.e. an AnnotatedString, where a plain string literal would discard them. Use it for any message containing colored text.
