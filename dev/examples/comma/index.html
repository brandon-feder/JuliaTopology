Comma categories

A tour of comma categories, slices and coslices over FinSet. To run this script yourself, use julia --color=yes --project=. examples/comma.jl.

using JuliaTopology

X, A, B = FinSet[1:2], FinSet[1:3], FinSet[1:4]
x, a, b = @ascat(X), @ascat(A), @ascat(B)

The arrow category

Id ↓ Id is the arrow category of FinSet: its objects are maps, and its morphisms are commuting squares.

I = id(Cat[FinSet])
K = I ↓ I
(Id ↓ Id)
├─ F Id :: FuncIdentity
│  └─ ∈ Iso(FinSet, FinSet)
│     ├─ domain   FinSet :: CatFinSet
│     ├─ codomain FinSet :: CatFinSet
│     └─ in       Cat :: CatCat
└─ G Id :: FuncIdentity
   └─ ∈ Iso(FinSet, FinSet)
      ├─ domain   FinSet :: CatFinSet
      ├─ codomain FinSet :: CatFinSet
      └─ in       Cat :: CatCat
h = Hom(A, X)[t -> x[mod1(object(t), 2)]]
println(K[ObjComma(A, X, h)])
(1:3, 1:2, {1 ↦ 1, 2 ↦ 2, 3 ↦ 1}) ∈ (Id ↓ Id)

Slices

The slice over X has the maps into X as its objects.

S = Slice(X)
f = S[h]
g = S[Hom(B, X)[t -> x[mod1(object(t), 2)]]]
println(f, "\n", g)
{1 ↦ 1, 2 ↦ 2, 3 ↦ 1} ∈ FinSet/1:2
{1 ↦ 1, 2 ↦ 2, 3 ↦ 1, …} ∈ FinSet/1:2

A morphism of the slice is a map A → B making the triangle commute:

println(Hom(f, g)[Mono(A, B)[t -> b[object(t)]]])
{1 ↦ 1, 2 ↦ 2, 3 ↦ 3} ∈ Hom({1 ↦ 1, 2 ↦ 2, 3 ↦ 1}, {1 ↦ 1, 2 ↦ 2, 3 ↦ 1, …})

A map which does not commute is rejected:

try
    Hom(f, g)[Hom(A, B)[t -> b[object(t) + 1]]]
catch e
    showerror(stdout, e)
end
NotInCategory: The morphism {1 ↦ 2, 2 ↦ 3, 3 ↦ 4} is not in Hom({1 ↦ 1, 2 ↦ 2, 3 ↦ 1}, {1 ↦ 1, 2 ↦ 2, 3 ↦ 1, …}), since it does not commute: the element 1 is sent to 1 by G(β) ∘ h but to 2 by h′ ∘ F(α).

id(X) is the terminal object, and f is its own unique morphism into it:

println(canonicalHom(f, terminal(S)))
{1 ↦ 1, 2 ↦ 2, 3 ↦ 1} ∈ Hom({1 ↦ 1, 2 ↦ 2, 3 ↦ 1}, {1 ↦ 1, 2 ↦ 2})

Coslices

Dually, the coslice under X has the maps out of X as its objects, and id(X) is its initial object.

C = Coslice(X)
k = C[Hom(X, A)[t -> a[object(t)]]]
println(canonicalHom(initial(C), k))
{1 ↦ 1, 2 ↦ 2} ∈ Hom({1 ↦ 1, 2 ↦ 2}, {1 ↦ 1, 2 ↦ 2})
