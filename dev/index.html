JuliaTopology.jl

JuliaTopology represents mathematical objects as plain Julia values paired with the Category they belong to. Morphisms are themselves objects of categories such as Hom(A, B), so the same machinery checks, prints and explains all of them.

Installation

using Pkg
Pkg.add(url="https://github.com/brandon-feder/JuliaTopology.git")

A first example

using JuliaTopology

A, B = FinSet[1:3], FinSet[[:a, :b]]
a, b = ascat(A), ascat(B)
f = Hom(A, B)[[a[1] => b[:a], a[2] => b[:b], a[3] => b[:a]]]
f(a[2])
:b :: Symbol
└─ ∈ ascat([:a, :b])
   └─ of [:a, :b] :: Vector{Symbol}
      └─ ∈ FinSet :: CatFinSet
