Getting started

A first look at objects, elements and morphisms, using finite sets. To run this script yourself, use julia --color=yes --project=. examples/getting-started.jl.

using JuliaTopology

Objects

Any Julia value can be paired with the category it belongs to. FinSet[x] makes x an object of the category of finite sets, checking that it is one.

A, B = FinSet[1:3], FinSet[[:a, :b]]
(1:3 ∈ FinSet, [:a, :b] ∈ FinSet)

Elements

The elements of a finite set form a category of their own, ascat(A), and a[x] is the element x of A.

a, b = ascat(A), ascat(B)
a[2]
2 :: Int64
└─ ∈ ascat(1:3)
   └─ of 1:3 :: UnitRange{Int64}
      └─ ∈ FinSet :: CatFinSet
(2 in a, 7 in a)
(true, false)

Morphisms

A morphism from A to B is an object of the category Hom(A, B). It can be given by its pairs of elements,

f = Hom(A, B)[[a[1] => b[:a], a[2] => b[:b], a[3] => b[:a]]]
{1 ↦ :a, 2 ↦ :b, 3 ↦ :a} :: GenericMorphFinSet
└─ ∈ Hom(1:3, [:a, :b])
   ├─ domain   1:3 :: UnitRange{Int64}
   ├─ codomain [:a, :b] :: Vector{Symbol}
   └─ in       FinSet :: CatFinSet

or by a function on elements, and is applied like one. With values=true, the pairs or function are written on plain values instead:

g = Hom(B, A)[y -> y == :a ? 1 : 2, values=true]
f(a[2])
:b :: Symbol
└─ ∈ ascat([:a, :b])
   └─ of [:a, :b] :: Vector{Symbol}
      └─ ∈ FinSet :: CatFinSet

Whether a map is injective, surjective or bijective is a property of it:

(isMono(f), isEpi(f), isIso(f))
(false, true, false)

Morphisms compose, and bijections have inverses:

g ∘ f
{1 ↦ 1, 2 ↦ 2, 3 ↦ 1} :: GenericMorphFinSet
└─ ∈ Hom(1:3, 1:3)
   ├─ domain   1:3 :: UnitRange{Int64}
   ├─ codomain 1:3 :: UnitRange{Int64}
   └─ in       FinSet :: CatFinSet
s = Hom(A, A)[x -> mod1(x + 1, 3), values=true]
inv(s)
{1 ↦ 3, 2 ↦ 1, 3 ↦ 2} :: GenericMorphFinSet
└─ ∈ Hom(1:3, 1:3)
   ├─ domain   1:3 :: UnitRange{Int64}
   ├─ codomain 1:3 :: UnitRange{Int64}
   └─ in       FinSet :: CatFinSet

A map which is not well defined is rejected, with an explanation:

try
    Hom(A, B)[[a[1] => b[:a], a[2] => b[:b]]]
catch e
    showerror(stdout, e)
end
NotInCategory: The map
    {1 ↦ :a, 2 ↦ :b, 3 ↦ ?}
is not a morphism in Hom(1:3, [:a, :b]), since it does not map 3.

Printing

Values print on one line inside messages and collections, and as a tree of every layer, with their Julia types, in the REPL:

f
{1 ↦ :a, 2 ↦ :b, 3 ↦ :a} :: GenericMorphFinSet
└─ ∈ Hom(1:3, [:a, :b])
   ├─ domain   1:3 :: UnitRange{Int64}
   ├─ codomain [:a, :b] :: Vector{Symbol}
   └─ in       FinSet :: CatFinSet
