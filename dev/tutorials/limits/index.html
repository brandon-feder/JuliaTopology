Limits and colimits

Limits and colimits of finite diagrams of finite sets. To run this script yourself, use julia --color=yes --project=. examples/limits.jl.

using JuliaTopology

A, B, C = FinSet[1:4], FinSet[[:a, :b]], FinSet[[:even, :odd]]
a, b, c = ascat(A), ascat(B), ascat(C)
parity = Hom(A, C)[x -> iseven(x) ? :even : :odd, values=true]

Diagrams

A diagram is a functor from the free category on a finite graph. Common shapes have shortcuts: here, the parallel pair parity, allOdd: A ⇉ C.

allOdd = Hom(A, C)[x -> c[:odd]]
D = parallelPair(parity, allOdd)
Diagram(X: 1:4, Y: [:even, :odd]) :: FuncDiagram
└─ ∈ Hom(FreeCat(X, Y; f: X → Y, g: X → Y), FinSet)
   ├─ domain   FreeCat(X, Y; f: X → Y, g: X → Y) :: FreeCat
   ├─ codomain FinSet :: CatFinSet
   └─ in       Cat :: CatCat

Products

A limit is a cone: an apex with a leg to each set of the diagram. The product of A and B has the pairs as its elements, and the projections as legs.

P = product(A, B)
apex(P)

Equalizers and pullbacks

The equalizer of parity and allOdd has one element for each odd number.

E = equalizer(parity, allOdd)
collect(apex(E))
2-element Vector{ObjectInCategory{<:NamedTuple, OICAsCat{Vector{NamedTuple}, CatFinSet}}}:
 (X: 1, Y: :odd) ∈ ascat(NamedTuple[(X = 1 ∈ ascat(1:4), Y = :odd ∈ ascat([:even, :o…)
 (X: 3, Y: :odd) ∈ ascat(NamedTuple[(X = 1 ∈ ascat(1:4), Y = :odd ∈ ascat([:even, :o…)

The pullback of parity and a map B → C pairs up elements with the same image:

side = Hom(B, C)[y -> c[y == b[:a] ? :even : :odd]]
PB = pullback(parity, side)
collect(apex(PB))
4-element Vector{ObjectInCategory{<:NamedTuple, OICAsCat{Vector{NamedTuple}, CatFinSet}}}:
 (A: 1, B: :b, C: :odd) ∈ ascat(NamedTuple[(A = 1 ∈ ascat(1:4), B = :b ∈ ascat([:a, :b]), C…)
 (A: 2, B: :a, C: :even) ∈ ascat(NamedTuple[(A = 1 ∈ ascat(1:4), B = :b ∈ ascat([:a, :b]), C…)
 (A: 3, B: :b, C: :odd) ∈ ascat(NamedTuple[(A = 1 ∈ ascat(1:4), B = :b ∈ ascat([:a, :b]), C…)
 (A: 4, B: :a, C: :even) ∈ ascat(NamedTuple[(A = 1 ∈ ascat(1:4), B = :b ∈ ascat([:a, :b]), C…)

The universal property

Any other cone over the same diagram factors uniquely through the limit, by canonicalHom:

X = FinSet[[:x, :y]]
x = ascat(X)
cone = Cone(discrete(A, B))[
    (X1 = Hom(X, A)[t -> a[1]], X2 = Hom(X, B)[t -> t == x[:x] ? b[:a] : b[:b]])]
canonicalHom(cone, P)
{:x ↦ (X1: 1, X2: :a), :y ↦ (X1: 1, X2: :b)} :: GenericMorphComma
└─ ∈ Hom([:x, :y], Generator{ProductIterator{Tuple{ObjectInCategory{UnitRange{…)
   ├─ domain   [:x, :y] :: GenericComma
   ├─ codomain Generator{ProductIterator{Tuple{ObjectInCategory{UnitRange{… :: GenericComma
   └─ in       Cone(Diagram(X1: 1:4, X2: [:a, :b]))
      ├─ F Δ :: FuncDiagonal
      │  └─ ∈ Hom(FinSet, [FreeCat(X1, X2), FinSet])
      │     ├─ domain   FinSet :: CatFinSet
      │     ├─ codomain [FreeCat(X1, X2), FinSet] :: FunctorCat{FreeCat, CatFinSet}
      │     └─ in       Cat :: CatCat
      └─ G Diagram(pt: Diagram(X1: 1:4, X2: [:a, :b])) :: FuncDiagram

A cone that does not commute with its diagram is rejected:

try
    Cone(D)[(X = Hom(X, A)[t -> a[2]], Y = Hom(X, C)[t -> c[:odd]])]
catch e
    showerror(stdout, e)
end
NotInCategory: The morphism ({:x ↦ :x, :y ↦ :y}, {1 ↦ :odd, 2 ↦ :even, 3 ↦ :odd, …}) is not in Hom(([:x, :y], 1:4, {:x ↦ 2, :y ↦ 2}), ([:x, :y], [:even, :odd], {:x ↦ :odd, :y ↦ :odd})), since it does not commute: the element :x is sent to :even by G(β) ∘ h but to :odd by h′ ∘ F(α).

Colimits

A colimit is a cocone, whose apex is a set of equivalence classes, each shown by a representative. The coequalizer of parity and allOdd identifies :even with :odd, leaving one class:

Q = coequalizer(parity, allOdd)
collect(apex(Q))
1-element Vector{ObjectInCategory{@NamedTuple{vertex::Symbol, element::ObjectInCategory{Int64, OICAsCat{UnitRange{Int64}, CatFinSet}}}, OICAsCat{Vector{@NamedTuple{vertex::Symbol, element::ObjectInCategory{Int64, OICAsCat{UnitRange{Int64}, CatFinSet}}}}, CatFinSet}}}:
 (vertex: :X, element: 1) ∈ ascat(@NamedTuple{vertex::Symbol, element::ObjectInCategory{Int64…)

The coproduct is the disjoint union, and the pushout glues along a common domain:

collect(apex(coproduct(A, B)))
